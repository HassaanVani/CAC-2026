# Common identity

Common's mark is an original, code-native SVG design. An open C makes the outer ear contour; a smaller inner curve echoes an ear canal / hearing-aid tube, ending in a small receiver-like dot. Rounded strokes keep it legible and approachable at favicon scale.

- `public/common-mark.svg`: standalone transparent mark, ink green `#285b4d`.
- `public/common-logo.svg`: standalone mark plus wordmark.
- `public/favicon.svg`: mark on rounded warm-ivory ground.

The interface uses the standalone mark alongside a live-text Manrope wordmark so the brand remains crisp and readable. Palette: ivory `#f4f3eb`, paper `#fffef9`, ink `#263d35`, green `#285b4d`, and muted sage accents. DM Sans provides interface typography, with Georgia for editorial headings. Both downloaded font families are served locally.

The mark is a symbolic visual identity, not an indication that Common is a hearing aid or medical device. No AI bitmap asset or third-party logo artwork is used.
